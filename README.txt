DeskFence 桌面格子
==================

运行：双击 DeskFence.exe（Win10/11 自带 .NET Framework 4.x，不用装别的）。
      运行后右下角托盘有个蓝色方格图标，所有全局设置在托盘右键菜单里。
      如果被杀毒软件拦截（自己编译的程序没有签名），选择"允许"即可，
      也可以双击 build.bat 用系统自带编译器从源码重新生成 exe。

格子操作
- 新建：托盘右键 → 新建格子；或双击托盘图标；或格子空白处右键 → 新建格子
- 命名：双击标题；或右键 → 重命名
- 移动：按住标题栏拖动
- 改大小：拖右边缘 / 下边缘 / 右下角
- 锁定：点标题栏左边的锁图标（锁定后不能移动和改大小，还能放文件）
        托盘菜单可"全部锁定 / 全部解锁"
- 折叠：点标题栏最左边的 ^，只剩标题栏
- 图标模式 / 列表模式：点标题栏右边的切换按钮（田 / ☰）
- 设置：点标题栏最右边的齿轮，弹出和托盘右键一样的设置菜单
- 透明度：托盘 或 格子右键 → 调整透明度...
        两个滑块：背景不透明度（5%~95%）、整体不透明度（含图标和文字，30%~100%）
        拖动时实时生效，点取消恢复原样
- 删除格子：右键 → 删除这个格子（里面的文件放回桌面，文件本身不删）

文件操作
- 收纳：把桌面上的文件/快捷方式/文件夹直接拖进格子
        文件会从桌面移走（不是隐藏），只显示在格子里
        实际存放在 %LOCALAPPDATA%\DeskFence\Store（和桌面同一个盘，移动是瞬间完成的）
        从别的文件夹拖进来的文件只是加个引用，不移动
        DeskFence.exe 本身不能放进格子（否则开机找不到它），可以拖它的快捷方式进来
        正在被打开的文件（比如 Excel 开着）暂时留在桌面，关掉后 20 秒内自动收进来
- 打开：双击图标
- 右键文件：和资源管理器一样的文件菜单（打开方式、发送到、复制、压缩、属性等），
        最上面是"移出格子"；按住 Shift 再右键显示更多选项；"重命名"直接在这里改名
- 文件名太长显示不全时：鼠标停在文件上，会弹出完整文件名
- 排序：在格子里拖动图标调整位置；或右键 → 按名称排序
- 换格子：把图标从一个格子拖到另一个格子
- 拖给别的程序：比如拖到微信发送；拖到文件夹里是"复制"
- 放回桌面：把图标拖出格子、在桌面空白处松手；或图标上右键 → 移出格子

退出与文件位置
- 菜单里有两种退出：
  "退出（文件放回桌面）"：所有收纳的文件放回桌面原来的位置，下次启动再收回格子
  "退出（文件不恢复到桌面）"：文件留在存放文件夹里，下次启动照常显示在格子里
- 程序崩溃、卡死被结束、关机、重启时：文件不动，留在存放文件夹里，
  开机后 DeskFence 自动启动，照常显示在格子里
- 放回桌面时如果桌面上已有同名文件，会自动改名为"名字 (2)"，不会覆盖
- 实际存放位置写在配置文件 %APPDATA%\DeskFence\config.xml 开头的说明里

文件位置（设置菜单 → 文件位置）
- 可以自定义"存放文件夹"（收纳的文件放在哪）和"配置文件位置"（config.xml 放在哪）
- 改存放文件夹时，已收纳的文件会一起搬过去；新位置和桌面不在同一个盘时，
  以后收纳/放回都要真正复制文件，会慢一些；存放文件夹不能选在桌面里面
- 改配置文件位置时，当前设置写到新位置，旧的 config.xml 删除
- 日志始终在 %APPDATA%\DeskFence\error.log
- 自定义的位置记在注册表 HKCU\Software\DeskFence；"恢复默认位置"可以改回去

语言
- 托盘 → 语言 / Language：中文、English、日本語，立即生效
  首次运行跟随系统语言

开机后
- 所有设置（格子位置、大小、名称、锁定、折叠、显示模式、透明度、语言、收纳的文件）
  每次改动后立即保存，重启后自动恢复
- 第一次运行会自动打开"开机自动启动"，不想要可在托盘里取消勾选
- 每次启动会把自启路径更新为当前 exe 位置，挪动 exe 后运行一次即可

布局
- 设置菜单 → 布局 → 保存当前布局...：给当前所有格子的位置/大小/折叠状态存一份，可存多份
- 布局 → 选一个 → 恢复这个布局：一键回到那次的摆放
- 每次启动、每次恢复布局前都会自动备份一份（最多保留 5 份"自动备份"）
- 远程桌面、换分辨率、拔显示器时，看不见的格子只是临时挪进屏幕，
  保存的位置不变，屏幕恢复后自动回到原位

托盘图标
- 设置菜单 → 隐藏托盘图标：勾选后托盘不显示，重启电脑后仍然保持隐藏
- 隐藏后打开设置：点任意格子右上角的齿轮
- 想恢复托盘图标：再双击运行一次 DeskFence.exe（不会开第二个），或在设置里取消勾选
- 如果把所有格子都删掉了，托盘图标会自动恢复，避免找不到设置

其他
- 配置保存在 %APPDATA%\DeskFence\config.xml，出错日志在同目录 error.log
- 按 Win+D 显示桌面时格子不会被隐藏；格子始终在其他窗口下面
